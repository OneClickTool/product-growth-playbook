# Instagram skills

Agent Skills for Instagram. Each `SKILL.md` works in Claude Code, Codex, Claude.ai or by hand; each has a
copy-paste prompt. They're installed with the rest of the playbook (see the root README).

| Skill | What you get | Time |
|---|---|---|
| [social-instagram](social-instagram/SKILL.md) | **Start here.** One command: `/social-instagram post · week · month · profile · story · numbers · risk · flow` | 1 min |
| [social-instagram-image-flow](social-instagram-image-flow/SKILL.md) | One fact → one finished post in 10 steps: format, hooks, slides, design kit, caption, alt text, link path, measuring | 45–90 min per post |
| [social-instagram-growth](social-instagram-growth/SKILL.md) | **Starter mode.** Profile once, then 5 posts + Stories a week, daily routine, Sunday numbers with keep/drop rules | 90 min setup + 2–3 h/week |
| [social-instagram-engine](social-instagram-engine/SKILL.md) | **Operator mode.** 8 engines in parallel: content factory, hook lab, niche accounts, creators, collabs, DM, paid on winners, search; budget tiers and kill rules | 1 day setup + 12–15 h/week |
| [social-instagram-creators](social-instagram-creators/SKILL.md) | Creator program: 100-creator list, 60–100 DMs/week, gifted → paid packs → retainers, brief, disclosure, per-creator UTM | 2–3 h setup + 2–4 h/week |

**Order:** profile (once) → growth (weekly plan) → image flow (each post) → after 2 weeks, engine + creators. Or just type `/social-instagram`.

Installed as a plugin, the command is `/product-growth-hack:social-instagram <command>`; copied into
`.claude/skills/`, it's `/social-instagram <command>`.

[social-credible-posting](../../skills/social/social-credible-posting/SKILL.md) (proof rules),
[X kit](../../x-marketing/README-X-Marketing.md) (same fact bank, other channel).
