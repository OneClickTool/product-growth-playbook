# 05 · Post formats: 12 kinds and the weekly rotation

Each format says what it's for (reach, trust, visit), the shape, and the signal it aims at. All of them go through
the [image flow](04-image-flow.md).

## The 12 formats

| ID | Format | Shape | Aims at | Fits |
|---|---|---|---|---|
| I01 | **Step-by-step how-to** | Carousel 6–10 | Saves, time spent | Any product with a process |
| I02 | **Before / after** | Carousel 3–5 or Reel 7–15 s | **Sends** | Cleaners, organisers, editors, games |
| I03 | **Checklist** ("before you X, check these 7") | Carousel 8–10 | **Saves** | Workflows, setups |
| I04 | **Settings / tips that work without the product** | Carousel 6–8 | Sends, follows | Every niche; builds trust |
| I05 | **Mistakes** ("5 things that fill your Mac") | Carousel 6–8 | Sends, comments | Problem-aware buyers |
| I06 | **Feature tour** (one feature per slide, real screenshots) | Carousel 5–8 | Profile visits | Hero product, once a month |
| I07 | **Demo Reel** (screen recording, result in second 1) | Reel 7–30 s | Watch to end, reshare | Anything that moves |
| I08 | **Behind the scenes** (a decision, a bug, a sketch → shipped) | Carousel 4–6 | Comments, trust | Builders' audience |
| I09 | **Honest numbers** (dated, small base stated) | Single or carousel 3 | Trust, follows | Once you have real numbers |
| I10 | **Result card** (recap card, clean desktop, finished level) | Single 3:4 | Likes, sends | Visual products |
| I11 | **Question / poll** (Story stickers, or a carousel ending in a question) | Story or carousel | Replies → content ideas | Weekly |
| I12 | **Offer / launch** (what it is, who it's for, price, trial, path) | Carousel 4–5 + Story with link | Link taps | Max 1 in 5 posts |

## The weekly rotation (Practice)

| Day | Post | Story (with link sticker?) |
|---|---|---|
| Mon | **I01 / I03** carousel (teach) | Reshare the post + link ✅ |
| Tue | — | Behind the scenes, poll sticker |
| Wed | **I07** demo Reel (Trial Reel if it's a new format) | Reshare + link ✅ |
| Thu | **I02 / I05** carousel (send-able) | — |
| Fri | **I10** single result image or **I08** | Question sticker (I11) |
| Sat | — | Weekly "what shipped" + link ✅ |
| Sun | **I04 / I06 / I09 / I12** (one offer post a week at most) | — |

Rules: one product per post; rotate products so each gets at least one post every 2 weeks; never the same format for
the same product two weeks in a row; tag the post file with `format: I0x` and compare on Sunday.
