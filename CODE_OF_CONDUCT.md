# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, critique ideas rather than people, and don't use issues or
Discussions to advertise. Sharing a tool is fine when it answers the question and you say it's yours.

Report unacceptable behaviour privately to the maintainer via [GitHub](https://github.com/nvminhtu).
Reports are handled confidentially.
