# 📚 Case Studies — real launches, taken apart

Short teardowns of how real products got launched and found, written so you can copy the **method**, not the product.
Each one is a single page: what they did, what we could verify (with sources and dates), what's worth copying, what to
avoid, and a checklist to run it on your own product.

Want to do the teardown yourself? Use the skills in [skills/case-study](../skills/case-study/README.md).
This folder is the reading list; those are the how-to guides.

## Rules for this folder
- One file per case: `YYYY-MM-<who>-<what>.md`. Newest at the top of the table.
- Every number has a source and the date it was seen. No source → write *not public*.
- Write it as a method anyone can reuse. Don't write "my app will do X".
- Prices and stats change. Treat everything as "true on the date in the file".
