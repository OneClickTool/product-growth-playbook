# 30-day X plan, day by day (2026-10-12 → 2026-11-08)

> Disclosure: product posts are about the maintainer's own products (OneClickTool), from each product page (checked
> 2026-10-11). Built on the real baseline in [flow/analytics-pattern.md](../flow/analytics-pattern.md) and the day in
> [flow/a-day-on-x.md](../flow/a-day-on-x.md). Agent version of any day: `/social-x today`.

**Where we start (2026-10-11):** 2K impressions / 28 days, 7 profile visits, 0 shares. Last 3 days ran 3–6 posts and
5–9 replies a day, and X put a temporary reach label on the account. So this plan **lowers posts to 1–2 a day and moves
the effort into replies**, then grows slowly.

**Targets for 2026-11-08** (goals, not a forecast): 10K impressions / 28 d · 50 profile visits · 15 bookmarks + shares
· `utm_source=x` link clicks tracked weekly · 0 labels.

## How to read a day

- **P1** = post at 08:00 · **P2** = post at 17:30 (at least 4 h after P1).
- Product posts: hook letters from [product-rotation.md](product-rotation.md); link in the first reply, `utm_content=<date>`.
- Talk posts: IDs from [talk-bank.md](talk-bank.md) (A = tip, B = question/poll, C = take, D = build log, E = numbers).
- **R** = replies by hand, split big accounts / peers / buyer sources ([docs/06-reply-playbook.md](../docs/06-reply-playbook.md)).
- **🔗** = may drop one product link today in a "what are you building?" post, only if one passes the 6 checks in
  [docs/06-reply-playbook.md](../docs/06-reply-playbook.md#what-are-you-building-posts-drop-your-link-or-not).
- **F** = max new follows (people you replied to and would reply to again).

**The one number:** profile visits, last 7 days, read each morning (targets: wk1 ≥ 5 · wk2 ≥ 8 · wk3 ≥ 11 · wk4 ≥ 14).
How to read it: [analytics-pattern.md](../flow/analytics-pattern.md#the-one-number-to-watch-every-day).

```text

[ ] answer overnight replies  [ ] P1  [ ] reply session 1  [ ] lunch answers + peers  [ ] P2  [ ] reply session 2
[ ] 🔗 only if a post passes the 6 checks  [ ] follows ≤ F  [ ] one fact-bank line  [ ] no hashtags unless a real community uses one
```

## Stop signs (do this, not more posting)
| Sign | Do |
|---|---|
| Reach label again | Drop to week-1 volume for 7 days; no links in replies that week |
| Impressions up, profile visits flat | Fix bio + pin, not posts |
| Profile visits up, link clicks flat | Bio link / offer unclear; test the pinned post's first line |
| Clicks up, installs flat | The landing / store page, not X ([launch-quick-download-wins](../../../skills/launch/launch-quick-download-wins/SKILL.md)) |
| Someone says "spam" under a link reply | Stop link replies for 2 weeks |
