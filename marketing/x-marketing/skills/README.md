# X skills

Agent Skills for X (Twitter). Each `SKILL.md` works in Claude Code, Codex, Claude.ai or by hand; each has a
copy-paste prompt. They're installed with the rest of the playbook (see the root README).

| Skill | What you get | Time |
|---|---|---|
| [social-x](social-x/SKILL.md) | **Start here.** One command: `/social-x today · week · month · reply · drop · profile · promo · talk · numbers · premium · risk` runs the right skill or doc | 1 min |
| [social-x-daily](social-x-daily/SKILL.md) | Today's 2 posts (max one product), first-reply link, 3 reply sessions, hourly checklist | 5 min + 25–120 min/day |
| [social-x-growth](social-x-growth/SKILL.md) | Product fact bank → 7 posts a week, ranker rules, Premium usage, funnel | 60 min + 30 min/week |
| [social-x-reply](social-x-reply/SKILL.md) | Target list, 20-minute daily reply session, 5 reply shapes, reply prompt | 20 min/day |
| [social-x-profile-funnel](social-x-profile-funnel/SKILL.md) | Bio, link, banner, pinned demo + offer, weekly funnel check | 45 min + 10 min/week |

**Order:** profile funnel (once) → growth (weekly batch) → daily + reply (every day). Or just type `/social-x`.

Installed as a plugin, the command is `/product-growth-hack:social-x <command>`; copied into `.claude/skills/`, it's `/social-x <command>`.
