# Post variant templates

One file per variant, in the [post-file](../post-file.md) format, so each one can be copied straight into
`marketing/x/NN-<day>-<topic>.md` (and shows up in campaign tools that read that format). Why each variant exists and
when to use it: [docs/09-post-variants.md](../../docs/09-post-variants.md). Rules for all of them:
[docs/10-best-practices.md](../../docs/10-best-practices.md).
