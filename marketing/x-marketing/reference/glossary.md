# X wiki: words used in this folder

| Term | Meaning |
|---|---|
| **For You** | X's ranked home feed: posts from people you follow plus recommended posts from people you don't |
| **Following** | The feed of only accounts you follow |
| **In-network / out-of-network (OON)** | Posts from accounts the viewer follows / doesn't follow. OON posts get a discount factor in ranking |
| **Phoenix** | The model in X's ranker that predicts each viewer's chance of each action |
| **Action weight** | Number multiplied by a predicted probability (reply 5, like 0.5, report −234 …) |
| **Author diversity** | Ranking decay for each extra post from the same author in one feed |
| **New-author boost** | Lift for authors with few impressions, so new accounts get tested |
| **Dwell** | Time a viewer spends on a post; "not dwelled" is a small negative |
| **Mutual / bidirectional follow** | You follow each other; replies between you get an extra boost |
| **Reply prioritization** | Premium feature: subscribers' replies rank higher in a conversation |
| **Long post** | Premium post up to 25,000 characters; feed shows the start, then "Show more" |
| **Article** | Long-form page on X; listed under Premium+ on the help page |
| **Media Studio** | studio.x.com, library for your uploaded media (Premium and up) |
| **Under the Hood** | X transparency tool showing labels that can limit your account's or posts' visibility |
| **Creator Subscriptions** | Followers pay you monthly for subscriber-only content (eligibility rules apply) |
| **Original Content Rewards** | Payouts based on qualified impressions from Premium users |
| **UTM** | `utm_source` / `utm_medium` / `utm_campaign` tags on a link so analytics knows it came from X |
| **Fact bank** | Your list of true, dated facts per product; the only material posts may use |
| **Hero product** | The one product your bio and pinned post sell |
| **PFP** | Profile picture. "Community / matching PFPs" = a group using one avatar style, see [trends](trends.md) |
| **CC0** | Public-domain license: art you may reuse freely, e.g. the Nouns collection |
