# Facebook skills

Agent Skills for Facebook. Each `SKILL.md` works in Claude Code, Codex, Claude.ai or by hand; each has a copy-paste
prompt. They're installed with the rest of the playbook (see the root README).

| Skill | What you get | Time |
|---|---|---|
| [social-facebook](social-facebook/SKILL.md) | **Start here.** One command: `/social-facebook today · groups · reply · post · page · own-group · numbers · fit · risk` runs the right skill or doc | 1 min |
| [social-facebook-groups](social-facebook-groups/SKILL.md) | 10–20 groups scored on fit and rules, answers that pass a 5-check test before the product is mentioned, one rule-checked post per group a month, UTM per group | 1 h, then 15–20 min/day |

**Order:** fit + profile and Page (once) → groups → answers every day → one post a week across groups. Or just type `/social-facebook`.

Installed as a plugin, the command is `/product-growth-hack:social-facebook <command>`; copied into `.claude/skills/`, it's `/social-facebook <command>`.

Also used by this kit, from the main library: [social-credible-posting](../../../skills/social/social-credible-posting/SKILL.md)
· [research-where-users-ask](../../../skills/research/research-where-users-ask/SKILL.md).
