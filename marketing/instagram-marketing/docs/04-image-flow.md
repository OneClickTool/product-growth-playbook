# 04 · The image flow: 10 steps from one fact to a post that brings visits

Every post in this kit goes through the same ten steps. They are written so a person or an agent can follow them
in order, and each step ends with something you can check. Time per post once the design kit exists: **45–90 min**
for a carousel, **30–60 min** for a Reel.

```text
 1 FACT ─ 2 FORMAT ─ 3 HOOK ─ 4 SCRIPT ─ 5 KIT ─ 6 VISUALS ─ 7 EXPORT ─ 8 CAPTION ─ 9 LINK PATH ─ 10 PUBLISH + MEASURE
 (what)   (shape)    (stop)   (swipe)    (look)  (make)      (check)    (search)    (visit)        (learn)
```

Agent version: [social-instagram-image-flow](../skills/social-instagram-image-flow/SKILL.md). Blank brief:
[templates/carousel-brief.md](../templates/carousel-brief.md). Post file: [templates/post-file.md](../templates/post-file.md).

> **Illustrative example.** Tidybox (a Mac cleaner) and Pinlog (an iPhone places app) are fictional products used
> to show the steps; their facts and numbers are made up.

---

## Step 1 · Pick ONE true fact (5 min)

Open the product's fact bank and pick **one** fact with a visible result. One post = one idea.

| Good fact (shows a result) | Weak fact (needs words to explain) |
|---|---|
| "Tidybox found 214 duplicates in my Downloads; Undo brings them back for 7 days." | "Tidybox is a powerful file manager." |
| "Pinlog makes a weekly 9:16 recap card of the places you went." | "Pinlog helps you remember things." |

✅ **Check:** you can say the post in one sentence that contains a noun you can *photograph* (a folder, a card, a
map, a screen). Any number must be real and dated, or the slide says `<NUMBER?>` until you have it.

## Step 2 · Pick the format (2 min)

| The fact is… | Format | Why ([03](03-how-instagram-ranks.md)) |
|---|---|---|
| A process (3–7 steps), a checklist, a list of settings | **Carousel, 6–10 slides** | Swiping = time spent; checklists get **saved** |
| A before → after | **Carousel, 3–5 slides** or **Reel 7–15 s** | Sent to friends who have the "before" problem |
| Something that moves (a banner drops in, files fly to Trash) | **Reel 7–30 s** (screen recording) | Watch-to-end + reshare |
| One striking result (a recap card, a clean desktop) | **Single image 3:4** | Fast to make; good on days you're short on time |
| A link you want tapped today | **Story sequence, 3 frames** | Only place for a tappable link ([06](06-stories-and-links.md)) |

Testing a format for the first time as a Reel? Post it as a **Trial Reel** (non-followers first, Reported).

✅ **Check:** the format column matches the fact column. Text-heavy idea → carousel, never a "mostly text" Reel.

## Step 3 · Write the hook slide (10 min)

The first slide (or the first second of a Reel) is the only thing most people see. Write **5 hooks**, pick one.

Hook formulas that fit a builder's voice (Practice):

| Formula | Example |
|---|---|
| **Pain in their words** | `Your Downloads folder has 3 copies of every PDF.` |
| **Number + result** | `214 duplicates. 1 click. 7-day undo.` (real number only) |
| **Before / after label** | `Downloads: before → after 20 seconds` |
| **"Settings you never changed"** | `5 Mac settings I change on every new laptop` |
| **Question they'd answer yes** | `Can't remember where you ate last Tuesday?` |
| **Honest limit** | `What my free app can't do (yet)` |

Rules for the hook slide:
- **≤ 8 words** of big text, readable on a phone at arm's length (title ≥ 90 px on a 1080-wide slide).
- **One image** that shows the problem (the messy folder), not the logo.
- No "Ever wondered", "You won't believe", "🚨", "Swipe →" alone. The content must make people swipe.

✅ **Check:** cover the text; the image alone still says what the post is about. Cover the image; the text alone
still makes sense.

## Step 4 · Script the slides (15 min)

Write every slide as one line in [templates/carousel-brief.md](../templates/carousel-brief.md) before opening a
design tool. Standard 8-slide shape:

| Slide | Job | Example (Tidybox, a fictional Mac cleaner: "clean Downloads in 20 s") |
|---|---|---|
| 1 | Hook | `Your Downloads has 3 copies of every PDF.` + screenshot of `report (1).pdf, report (2).pdf…` |
| 2 | Why it matters | `Duplicates + old installers = gigabytes you never open.` |
| 3–6 | One step / point per slide, image proves it | `Scan → duplicates found byte for byte` · `Old .dmg files flagged after 7 days` · `Big files flagged, never pre-selected` · `Moved to Trash, never deleted` |
| 7 | The result / proof | Clean folder screenshot. Real number with date, or no number |
| 8 | Ask + path | `Send this to someone with a messy Mac.` · `Free for 2 folders → link in bio` |

Rules: **one idea per slide, ≤ 25 words**, the image proves the words. Max one slide mentions the product by name
before slide 7. Only the last slide asks for anything. A **Reel** gets the same script as a shot list: second 0–1
result, 1–10 the steps, last 2 seconds the end card.

✅ **Check:** read only the slide text top to bottom; it's a complete mini-article. Every claim is in the fact bank.

## Step 5 · Build on the design kit (once, then 0 min)

Every post uses the same kit, so the grid looks like one brand and you never design from zero:
[templates/design-kit.md](../templates/design-kit.md).

| Item | Default (Practice) |
|---|---|
| Canvas | **1080 × 1440 (3:4)** for carousels and single images; **1080 × 1920 (9:16)** for Reels and Stories |
| Safe zone | 3:4: keep text **≥ 80 px** from every edge. 9:16: keep text out of the **top 250 px** and **bottom 350 px** (app buttons and captions sit there) |
| Colors | 1 background, 1 text, 1 accent (+ the product's own accent). Contrast ≥ 4.5 : 1 |
| Type | One bold sans for titles (90–120 px), one regular for body (40–52 px). Max 2 sizes per slide |
| Layouts | **A** big title + screenshot · **B** step number + one line + screenshot · **C** quote / number on color |
| Footer | Small handle + slide counter (`3/8`) in the same corner every time |

✅ **Check:** the 3 layouts exist as templates (Canva, Figma, Keynote or code). Changing one color updates all.

## Step 6 · Make the visuals (15–30 min)

Order of preference, because originality is judged ([03](03-how-instagram-ranks.md)):

1. **Real screenshots / screen recordings of your product** (test data, no personal info). Crop to the part that
   proves the slide; zoom so text reads on a phone.
2. **Device frames / mockups** around those screenshots (Mac window, iPhone frame).
3. **Simple diagrams** you draw (arrows, before/after columns, a 3-step flow).
4. **AI-generated images** only for backgrounds, metaphors or illustrations, **never** as a fake screenshot of your
   app or a fake result. Prompt pattern (paste into your image tool, Practice):

   ```text
   {{subject: e.g. a tidy desk with a single laptop, warm morning light}}. Flat editorial illustration, soft grain,
   palette {{bg}} / {{text}} / {{accent}} from my design kit, lots of empty space in the {{top third}} for a title,
   no text, no logos, no UI, portrait 3:4.
   ```

Record Reels at the device's native resolution; don't download your own TikTok with its watermark.

✅ **Check:** every slide's image shows exactly what its text says. No other app's logo or watermark. No real
names, emails, home addresses or file paths you wouldn't publish.

## Step 7 · Export and check (5 min)

- [ ] Carousels: all slides **same size** (the first slide's ratio is used for all, Reported), PNG or high-quality JPG, 1080 wide.
- [ ] Reels: 1080 × 1920, 30 fps+, sound on (music from Instagram's library or your own voice; muted Reels are
      shown less, Official), captions burned in or auto-captions on.
- [ ] Open every file **on your phone**: text readable without zoom, nothing under the safe-zone lines.
- [ ] A **cover** for Reels: frame 1 or a designed 9:16 cover whose middle 3:4 also works on the grid.
- [ ] File names `NN-<slug>-sMM.png` next to the post file, so the post can be rebuilt later.

## Step 8 · Caption, hashtags, alt text (10 min)

```text
Line 1 (≤ 125 chars, shows before "more"): the hook again, in search words.
   e.g. "How to find duplicate files on a Mac (and clean Downloads in 20 seconds)"
Lines 2–5: the steps in one line each, for people who don't swipe.
Line 6: the ask — "Send this to someone whose Mac is full." / "Save it for your next clean-up."
Line 7: the path — "Free for 2 folders. Link in bio → Tidybox." (no URL: it isn't clickable)
Last line: 3–5 specific hashtags (#macapps #macos #productivitytips), never #explore / #reels.
```

- [ ] **Alt text** on every image slide (Advanced settings → Write alt text, Official): what's on the slide, the
      words on it, one line each. It helps screen-reader users and describes the image to search.
- [ ] Location / topics: only if true and relevant.
- [ ] Collaborator tag only when the other account really co-made it.

## Step 9 · The link path to your website (5 min)

A caption URL does nothing. Pick the path **before** you publish, write it on the last slide and in the caption,
and set the link:

| Path | Set up | When |
|---|---|---|
| **Bio link** (default) | Move the product's link to position 1 with `utm_medium=bio&utm_campaign=<slug>&utm_content=<post-id>` | Every post |
| **Story link sticker** | 1–3 h after the post: 3-frame Story → frame 3 has the sticker, `utm_medium=story` ([templates/story-sequence.md](../templates/story-sequence.md)) | Every post that asks for a visit |
| **Highlight** | Add that Story to the product's Highlight | Always: the link lives on after 24 h |
| **Keyword → DM** | "Comment CLEAN and I'll DM you the link", answered by hand or an official Meta-partner tool, `utm_medium=dm` | Posts with many comments; the DM must contain exactly what was promised |

Full map, UTM table and GA4 report: [flow/website-funnel.md](../flow/website-funnel.md).

✅ **Check:** tap the bio link and the Story sticker on your phone; both land on the right page with UTM in the URL.

## Step 10 · Publish, answer, reshare, measure

| When | Do |
|---|---|
| Publish | Your usual slot. New Reel format → Trial Reel |
| First 60 min | Answer every comment with a real reply (a question back, a detail). Reply to DMs |
| +1–3 h | Story sequence with the link sticker; add to Highlight |
| +24 h | Trial Reel: share to followers if views/shares beat your last 5 Reels |
| +48 h | Log the numbers in [templates/weekly-numbers.md](../templates/weekly-numbers.md): reach, % non-followers, sends, saves, profile visits, link taps, landing visits by `utm_content` |
| Sunday | Keep / drop formats with the rules in [07](07-metrics-and-stop-rules.md) |

**Recycle the winner (Practice):** a carousel that beat your average → make its Reel version next week, and its
X version ([x-marketing](../../x-marketing/README-X-Marketing.md)). Same fact, new format: that's original, not a repost.

## The whole flow on one card (print it)

```text
[ ] 1 one real fact with a visible result
[ ] 2 format matches the fact (process→carousel, motion→Reel, result→single, link→Story)
[ ] 3 hook ≤ 8 words + one image of the problem
[ ] 4 slides scripted: 1 idea, ≤ 25 words, image proves it, only last slide asks
[ ] 5 design kit: 1080×1440 / 1080×1920, safe zones, 2 type sizes
[ ] 6 real screenshots first; AI only for backgrounds; no watermarks, no personal data
[ ] 7 same-size export, checked on the phone, Reel has sound + cover
[ ] 8 caption line 1 = search words, ask + path, ≤5 hashtags, alt text
[ ] 9 bio link #1 updated with UTM; Story sticker planned; Highlight
[ ] 10 first hour answered, Story posted, numbers logged at +48 h
```
