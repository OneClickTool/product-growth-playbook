# 05 · Pin design

Specs below are from [Pinterest Help: product specs](https://help.pinterest.com/en/business/article/pinterest-product-specs)
(written for ads; organic pins use the same shapes). Creative advice is from
[Pinterest Business: creative best practices](https://business.pinterest.com/creative-best-practices/).

## Specs

| Item | Value |
|---|---|
| Ratio and size | **2:3, 1000 × 1500 px**. Taller than 2:3 may be cut off in feeds |
| File | PNG or JPEG; up to 20 MB on desktop, 32 MB in the app |
| Title | Up to 100 characters; about the first 40 show in feeds |
| Description | Up to 800 characters per the specs page (the creative page says 500; keep under 500 to be safe); not shown in feeds, used for delivery |
| Video pin | MP4 / MOV / M4V, 4 s to 15 min; square or vertical (2:3, 4:5, 9:16) recommended |
| Carousel | 2–5 images, 1:1 or 2:3 |

## Layout that reads on a phone
Pinterest's own advice: vertical, logo or name visible but small, main visual in the middle, key message on top,
details at the bottom ("stacking"), short copy, a clear call to action.

```text
┌──────────────────────┐
│  HEADLINE (search    │  ← 3–7 words, big, high contrast: the result or the plan
│  words, 2 lines max) │
│                      │
│   [ the result:      │  ← screenshot in a device frame, the template page,
│     one clear image ]│     the desk, the before → after
│                      │
│  small detail line   │  ← "Free template · Mac & iPhone"
│  brand / URL, small  │  ← name or domain, never dominant
└──────────────────────┘
```

## Rules of thumb
- **Show the result, not the UI chrome.** The finished planner, the clean desktop, the edited photo.
- **One message per pin.** If you need two, make two pins.
- **Readable at thumbnail size.** Check it at 25% zoom. Text over busy photos needs a solid band.
- **Real screenshots.** If you use an AI image as a background, don't present it as a real customer or photo;
  Pinterest may add an "AI modified" label ([08-rules-and-risks.md](08-rules-and-risks.md)).
- **Your own or licensed images only.** Other people's pins aren't free stock.
- **Brand style kept constant** (font, 2–3 colours, logo position) so a profile looks like one shop.

## Tools
Any editor that exports 1000 × 1500 works: Figma, Canva, Keynote, Affinity. Keep one master file per variant
([06-pin-variants.md](06-pin-variants.md)) and swap the headline and image.
