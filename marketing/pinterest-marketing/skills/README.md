# Pinterest skills

Agent Skills for Pinterest. Each `SKILL.md` works in Claude Code, Codex, Claude.ai or by hand; each has a copy-paste
prompt. They're installed with the rest of the playbook (see the root README).

| Skill | What you get | Time |
|---|---|---|
| [social-pinterest](social-pinterest/SKILL.md) | **Start here.** One command: `/social-pinterest today · keywords · pin · boards · profile · numbers · fit · risk` runs the right skill or doc | 1 min |
| [social-pinterest-pin](social-pinterest-pin/SKILL.md) | 3–5 different pins for one page: search terms, image brief, title, description, board, UTM link, pin file | 20 min per page |

**Order:** fit + profile (once) → keywords and boards → pins every week. Or just type `/social-pinterest`.

Installed as a plugin, the command is `/product-growth-hack:social-pinterest <command>`; copied into `.claude/skills/`, it's `/social-pinterest <command>`.
