# TikTok skills

Agent Skills for TikTok slideshows. Each `SKILL.md` works in Claude Code, Codex, Claude.ai or by hand; each has a
copy-paste prompt. They're installed with the rest of the playbook (see the root README).

| Skill | What you get | Time |
|---|---|---|
| [social-tiktok-slideshow](social-tiktok-slideshow/SKILL.md) | **Start here.** Fit check, 10 "person + doubt" hooks, 3 ready-to-post 6-slide slideshows (text, locked scene, image prompts, caption), draft → sound → publish, labels | 60 min + 20–40 min/post |
| [social-tiktok-slideshow-loop](social-tiktok-slideshow-loop/SKILL.md) | Weekly report from your post log: fix CTA / fix hook / scale per post, scale / keep / retest / drop per hook formula, stop rules. Script: `scripts/slideshow_loop.py` (standard library) | 20 min/week |

**Order:** slideshow (make + post daily) → loop (every Sunday) → slideshow again with the winners.
