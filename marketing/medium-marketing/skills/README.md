# Medium skills

Agent Skills for Medium. Each `SKILL.md` works in Claude Code, Codex, Claude.ai or by hand; each has a copy-paste
prompt. They're installed with the rest of the playbook (see the root README).

| Skill | What you get | Time |
|---|---|---|
| [social-medium](social-medium/SKILL.md) | **Start here.** One command: `/social-medium fit · start · write · mirror · pubs · profile · numbers · risk` runs the right skill or doc | 1 min |
| [social-medium-article](social-medium-article/SKILL.md) | One article from a real question: type, title, first 3 lines, draft, a 5-check product test, topics, canonical, one UTM link | 2–3 h per article |

**Order:** `fit` (is it worth it?) → profile + import 2–3 posts → one article a week, or mirror mode. Or just type
`/social-medium`.

Installed as a plugin, the command is `/product-growth-hack:social-medium <command>`; copied into `.claude/skills/`,
it's `/social-medium <command>`.
