# Pattern taxonomy

Tag every product with the same short tags so you can count them. Only tag what you saw yourself. Add a new tag
only when 2+ products share it, and write down what it means here.

## Store page

| Tag | What to look for |
|---|---|
| `store-benefit-first` | The first screenshot caption states a benefit, not a feature name |
| `store-narrative` | Screenshots tell a story in order (problem → action → result) |
| `store-real-ui` | Screenshots show real UI, not only illustrations |
| `store-social-proof` | Awards, ratings or press quotes in screenshots |
| `store-video` | An app preview or promo video |
| `icon-single-symbol` | The icon is one simple symbol that is readable at small sizes |

## Onboarding / first run

| Tag | What to look for |
|---|---|
| `value-before-signup` | You can use the product before creating an account |
| `first-value-under-60s` | The first useful result in under 60 seconds (time it) |
| `one-question-personalize` | 1–3 questions that visibly change the first screen |
| `sample-content` | Demo data or a template instead of an empty screen |
| `permission-after-win` | Notification, location or camera asked only after the first success |
| `progress-indicator` | Steps or a progress bar during setup |
| `skippable-tutorial` | Any tutorial can be skipped |
| `swipe-tutorial` | 3+ intro slides before the app (often a control pattern) |

## Paywall

| Tag | What to look for |
|---|---|
| `paywall-after-onboarding` | The paywall shows right after setup |
| `paywall-after-value` | The paywall shows after the user gets a result |
| `paywall-trial-timeline` | Shows what happens on day 1, day X and when billing starts |
| `paywall-2-plans` | Two plans side by side, one marked as default |
| `paywall-soft-close` | Easy to close and keep using the free version |

## Identity and delight

| Tag | What to look for |
|---|---|
| `mascot` | A character that reacts to what the user does |
| `signature-motion` | One recognizable animation or haptic tied to the core action |
| `designed-empty-state` | Empty screens that explain what to do next |
| `platform-native` | Uses system components, widgets, Live Activities, Dynamic Type |
| `accessibility-visible` | Large text, VoiceOver labels and contrast work well (check them) |

## Shareable moment

| Tag | What to look for |
|---|---|
| `share-card` | A good-looking image of the user's result, ready to post |
| `share-prompt-after-win` | Asks to share or rate right after a success |
| `invite-loop` | Using it with a friend is part of the product |

## Launch page (Product Hunt, website)

| Tag | What to look for |
|---|---|
| `tagline-outcome` | The tagline promises an outcome, not a technology |
| `gallery-first-is-ui` | The first gallery image shows the product working |
| `launch-video-short` | A demo video under 60 seconds |
| `maker-comment-story` | The first comment tells why it was built and asks for specific feedback |
| `launch-offer` | A discount or perk for launch-day visitors |
