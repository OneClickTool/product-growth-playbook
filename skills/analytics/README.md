# 📊 Analytics

Learn Google Analytics 4 and Google Search Console well enough to answer two questions every week: *where do my
visitors come from?* and *which page or channel should I push harder?* For websites, landing pages, blogs and web
apps.

| Skill | What you get | Level | Time |
|---|---|---|---|
| [analytics-ga4-setup](analytics-ga4-setup/SKILL.md) | A GA4 property set up right once: tag, enhanced measurement, internal-traffic filter, cross-domain, 14-month retention, consent mode, Search Console link, all verified | Beginner | 60–90 min |
| [analytics-tracking-plan](analytics-tracking-plan/SKILL.md) | A one-page plan: 5–8 events, 1–3 key events, parameters, one UTM convention for every channel, a test checklist | Beginner | 45–60 min |
| [analytics-ga4-reports-101](analytics-ga4-reports-101/SKILL.md) | The 7 screens worth opening (6 in GA4 + Search Console Performance), a metrics glossary with API names, 7 practice lessons, your baseline note | Beginner | 1–2 h |

**Planned** (see [the area plan](../../docs/plan-analytics-ga4.md)): `analytics-traffic-diagnosis` (weekly check and
"why did traffic drop"), `analytics-traffic-growth-loop` (one lever a week from the data),
`analytics-funnel-and-conversion` (visit → key event), `analytics-agent-reporting` (read-only GA4 and Search
Console MCP reports for AI agents).

**Suggested order:** setup → tracking plan → reports 101, then repeat the reports-101 lessons 2, 4, 5 and 6 every
week.

**Not here:** mobile app analytics (Firebase) → [launch-growth-stack-setup](../launch/launch-growth-stack-setup/SKILL.md).
Visits from ChatGPT, Perplexity and AI Overviews → [launch-geo-aeo-feature-preview](../launch/launch-geo-aeo-feature-preview/SKILL.md).
