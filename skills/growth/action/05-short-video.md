# Step 5: Short video, batch-produced

**Weeks 3–6 · 9 videos, then 2–3 a week** · [← Step 4](04-listings-and-intent-pages.md) · Next: [Step 6](06-community-posting.md)

## Goal
Reach new people fast without a follower base. Short-form platforms show videos to non-followers, so a new account
can still get views if the first 2 seconds work.

Full method: [social-short-video](../../social/social-short-video/SKILL.md).

## Steps
- [ ] **Three formats** to test. For utility products these usually fit:
  - before → after,
  - "your <device> can do this and nobody told you",
  - speed run of a boring task done by the product.
- [ ] **10 hooks**: the first line on screen and the first thing said. Specific and visual.
- [ ] **Template it.** If you can generate video from code (for example with Remotion), build one template per
      format: hook text, screen recording slot, result, CTA. Then a new video is a new hook plus a new clip.
- [ ] **Post 9 videos in 3 weeks**: week 1 one per format, weeks 2–3 two more per format, changing only the hook.
      Same video on TikTok, Reels and Shorts, without other platforms' watermarks.
- [ ] **CTA with a tracked link** from step 1, in the bio or caption.
- [ ] **Log each video** in `growth/video-log.md`: views, % watched to the end, shares, profile visits, link clicks,
      installs.
- [ ] **Keep the winner**: the format with the best watch-through **and** clicks. Make only that format from now on.
      A video that gets 5–10× your usual views → 3 close variations within 72 hours.
- [ ] **Reuse** the winning clips on X and in community posts (step 6).

## Done when
9 videos posted and logged, one format chosen.

## Common mistakes
- Opening with "Hi, today I'll show you…". Show the result first.
- Judging by views. A video with fewer views and more installs wins.
- Changing the format every video, so nothing can be compared.
