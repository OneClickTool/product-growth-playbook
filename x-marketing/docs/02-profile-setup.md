# 02 · Profile setup checklist

Run it once, then re-check monthly. Agent version with a prompt: [social-x-profile-funnel](../skills/social-x-profile-funnel/SKILL.md).

- [ ] **Photo:** your face or one clear logo. Set it now; changing it later removes the checkmark until re-review
      ([About X Premium](https://help.x.com/en/using-x/x-premium)).
- [ ] **Name line:** name + what you make ("Alex · small Mac & iOS utilities").
- [ ] **@handle:** final. Same reason as the photo.
- [ ] **Bio (≤160):** who you help + what you made + one true proof.
- [ ] **Link:** one URL with `utm_source=x&utm_medium=bio&utm_campaign=profile`. Copy-ready links: [resources/links.md](../resources/links.md).
- [ ] **Banner:** real screenshot of the hero product + one line.
- [ ] **Pinned post:** 10–40 s demo + problem / what it does / offer. Re-pin monthly.
- [ ] **Location / website fields:** website = your hub page.
- [ ] **Professional / creator tools** (if offered in your region): turn on analytics access.
- [ ] **Media Studio** (Premium and up): upload demo clips there to reuse them.
- [ ] **Test the link** from a phone, logged out. Does the landing show the same offer as the pin?
