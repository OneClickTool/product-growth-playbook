# 05 · Post formats: the 7-day rotation, with fill-in templates

One original post a day, rotating products. Agent version (writes all 7 from your fact bank):
[social-x-growth](../skills/social-x-growth/SKILL.md). File format for Promo Desk or your repo:
[templates/post-file.md](../templates/post-file.md).
Want more than 7 kinds of post? The full set of 20 variants, grouped into Show / Teach / Prove / Talk / Sell, with a
copy-ready file each: [09-post-variants.md](09-post-variants.md). Rules for all of them: [10-best-practices.md](10-best-practices.md).

| Day | Format | Aims for |
|---|---|---|
| Mon | Demo | follow, profile visit |
| Tue | Number / lesson | reply, bookmark |
| Wed | Tip without your product | copy-link share |
| Thu | Behind the scenes | reply |
| Fri | Question / poll | reply (mutual boost) |
| Sat | Long post / thread | dwell, share |
| Sun | Weekly numbers + one offer | profile visit → landing |

## Templates (replace `{{ }}`, keep it under 280 unless it's Saturday)

**Mon · Demo**
```text
{{The annoying thing, in the user's words}}.
{{Product}} does it in {{N}} seconds:
[10–30 s clip, no music needed, captions on]
```

**Tue · Number with context**
```text
{{Metric}} went from {{A}} to {{B}} in {{time}}. Small base: {{n}}.
What changed: {{one specific change}}.
What didn't work: {{one thing}}.
```

**Wed · Tip that works without your product**
```text
{{Platform}} tip most people miss: {{exact steps}}.
{{What you get}}.
```

**Thu · Behind the scenes**
```text
Spent {{time}} on a bug: {{symptom}}.
Cause: {{cause, plain words}}. Fix: {{fix}}.
{{One lesson}}.
```

**Fri · Question**
```text
{{Buyers}}: {{specific choice A}} or {{choice B}}?
Building {{feature}} this week and genuinely split.
```

**Sat · Long post (Premium) or thread**
```text
{{Payoff in the first 280 characters: the result + the method name}}

1. {{step}} …
(close with: what you'd do differently + one question)
```

**Sun · Weekly numbers + offer**
```text
Week {{N}} building {{products}}:
Shipped: {{1–2 things}}
Numbers: {{real numbers vs last week}}
Learned: {{one line}}
{{Hero product}}: {{offer exactly as on the store}} → link in reply
```

## Rules of thumb
- First line must work alone in the feed.
- One idea per post, at most one emoji. Hashtags: 0, or 1 that a real community follows ([why](../reference/tips-and-tricks.md#hashtags)).
- Six posts give, one asks. Never post the same text twice.
- Every number true, dated, with its base. See [social-credible-posting](../../skills/social/social-credible-posting/SKILL.md).
